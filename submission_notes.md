## Instructions to Run
1. Install Python 3.10 or later.
2. Install dependencies: `pip install -r requirements.txt`
3. Run `python train_model.py` to download data and train/save the model.
4. Run `streamlit run app.py`.
5. Open `http://localhost:8501`.
6. Download sample input CSV from the app, upload it, and test predictions.
